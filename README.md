# 抽凭 — 合同合规性审阅 Agent

主路径：选底稿目标 → 工作台立笔（裁剪序时账）→ 上传凭证 → 缺字段才核对 → 测试不通过才确认结论 → 导出 GOSPD 底稿。

## V2：异常驱动审阅

前台只保留四个根入口：`工作台`、`待裁决`、`导出`、`更多`。正常项自动通过并默认隐藏，审计师主要处理缺件、低置信度、账载差异、关系歧义、规则冲突、测试失败、证据溯源缺口和质量抽样事件。

- **工作台**：一页查看多笔业务；每行业务可直接拖入或选择文件。已通过项折叠在“查看已通过”中。
- **资料整理**：混装 PDF 先按页拆分；连续页可合并为一张单据；边界、类型和业务归属均由人工最终确认。页面保留撤销历史，底部只有“确认整理并识别”一个主操作。
- **待裁决**：原件、账载值、单据值、AI 建议、置信度、触发原因和影响范围同屏。覆盖 AI、确认不通过或发现漏判时必须填写理由；缺件只能补传，不能按钮放行。
- **导出**：存在阻断时只显示“处理 N 个阻断项”；清零后替换为“生成并下载底稿”。
- **质量抽样**：从已自动通过且无开放事件的业务中，按风险与稳定随机两路抽取。复核无误只留痕；发现漏判会生成真正的阻断事件并使底稿失效。

V2 在独立分支 `feature/event-driven-ui-v2` 开发。升级前稳定版本已标记为 `pre-v2-event-ui-20260823`（提交 `a31d558`），需要回看旧版时可从该标签创建新分支，不要在有未提交文件时直接切换。
