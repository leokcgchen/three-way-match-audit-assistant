# GOSPD01030 验收矩阵与质量门禁

**适用目标：** `gospd01030`（销售截止·期后）  
**配套：** `docs/GOSPD01030_底稿填制指引与Prompt.md`、`templates/GOSPD01030.xlsx`  
**可执行门禁：** `python scripts/accept_gospd01030_gates.py`；单测 `pytest tests/test_gospd01030.py`

范围声明：本矩阵验收的是**已选样本细节测试底稿**的可复现性与填制纪律，不替代抽样设计，PASS ≠ 单据真实或总体完整。

---

## 1. 质量门禁（必须全绿）

| ID | 门禁 | 期望 | 实现锚点 |
|----|------|------|----------|
| G1 | 禁静默默认期末 | 无 `period_end` → `resolve_period_end=None`；期间结论 `NOT_TESTED`；M5 不写假日期 | `gospd01030_assertions.resolve_period_end` |
| G2 | 改期末级联失效 | `PUT /goals` 变更 `period_end` → 清三单/截止/Gate5/底稿 | `workflow_router.put_goals` |
| G3 | 导出只认 Gate4 | 未确认链不进样本行；日志 `NOT_TESTED` | `build_gospd01030_sample_rows` |
| G4 | 严格归链 | `allow_weak_unique_attach=False` 且 `allow_unique_so_ht_merge=False`；弱号/无互引不得猜链 | `gospd01030_filler` → `group_classified_by_chain` |
| G5 | V 公式不可覆盖 | 样本区 V 列以 `=` 开头且含 `$M$5` | `fill_gospd01030_workbook` |
| G6 | 公式冲突停写「是」 | 独立期间 ≠ V 口径 → `FORMULA_LOGIC_CONFLICT`，W 不得写 YES | assertions + filler |
| G7 | 缺证不写无异常 | 缺签收日/缺期末等 → W 空或「否」，不得 YES | assertions `INSUFFICIENT_EVIDENCE` / `NOT_TESTED` |
| G8 | W 写 DV 精确值 | 「否」须模板长文案，禁止短 `No 否` 绕过 | `_w_dv_labels` / filler |
| G9 | R 无金额不填 0 | 交货无可比金额 → R 空+灰度 | filler R 列 |
| G10 | 步骤3 应收期间 | `assert_ar_correct_period` 入断言与日志；收入否→应收否 | `program_matrix.ar_period` |
| G11 | 配方步骤 | 必做含三单截止；跳过合同条款/金额测试 | `resolve_workflow_plan(["gospd01030"])` |
| G12 | C 列禁 SO 冒充凭证 | 无 `ledger_voucher` 时订单号不得写入凭证列 | filler `_voucher_no` |

## 2. 场景验收用例

| UC | 场景 | 输入要点 | 期望结论 |
|----|------|----------|----------|
| UC01 | 期后签收+期后过账 | 控制权/过账均 > 期末 | 独立期间 YES；可与 V 一致 → W 可为「是」 |
| UC02 | 期内控制权+期后过账 | 签收 ≤ 期末，过账 > 期末 | 独立期间 No；W「否」+ X 说明 |
| UC03 | 公式冲突 | 独立 YES 但 P≤M5（V=No） | 冲突日志；W 空 |
| UC04 | 缺期末 | 无 period_end | NOT_TESTED；不落正式期间结论 |
| UC05 | Gate4 未确认 | matching_confirmed=false | 0 样本行；skipped NOT_TESTED |
| UC06 | 弱编号签收 | 仅 documentNo=R-x，无 orderNo | 进「未识别业务号」，不并入唯一 SO |
| UC07 | 无互引 SO+HT | 订单无 contractNo、合同无 orderNo | 两链分立，不盲合并 |
| UC08 | 步骤3 跟随收入否 | 收入期间 False | `ar_period.verdict=False` |
| UC09 | 双目标导出 | goals=[01010,01030] | 各出一份，顺序=勾选顺序 |

## 3. 明确不做 / 不得宣称

| 项 | 说明 |
|----|------|
| 抽样总体结论 | 仅已选样本 |
| 独立应收函证/坏账 | 步骤3 与收入同源过账日，非函证 |
| 4-4-5 等项目日历 | 当前自然日 + 报告期末边界 |
| LLM 直接改 V/W/公式 | 只允许确定性写入器；LLM 最多出填制计划 JSON |
| OCR Mock 正式口径 | 正式环境 `AUDIT_ALLOW_OCR_MOCK=0` |
| HITL API 门禁 | `REQUIRE_*=auto`：禁 Mock 时自动开；批测显式 `0`；独立三单/金额 API 须带 `job_id` |
