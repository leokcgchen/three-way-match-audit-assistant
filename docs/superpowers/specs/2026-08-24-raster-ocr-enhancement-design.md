# 图片 OCR 增强第一阶段设计

## 目标

将现有曝光、对比度、阴影修正、锐化与降噪算法接入正式 OCR 前处理。只覆盖 JPG、JPEG、PNG、WEBP、TIFF、BMP；单页预处理耗时必须低于 3 秒，不增加额外 OCR 调用。

## 数据流

`原图 → 亮度触发 → 几何校正 → 缺陷路由 → 单一增强方案 → 快速质量门 → JPEG → PaddleOCR`

- 白底系统导出图继续直通，不改变现有行为。
- 灰暗图完成方向、纠偏和边界拉平后，根据 `shadow / low_contrast / blurred / balanced / line_art` 选择至多一个增强方案。
- `shadow / low_contrast / blurred` 使用现有快速配方的保守首选变体；`balanced` 灰暗图使用彩色扫描增强；`line_art` 不增强，防止线条和小数点受损。
- 质量门只在 512 像素缩略图上比较对比度、清晰度和边缘密度；退化或异常时回退到几何校正图。
- 元数据记录增强路线、是否应用、是否回退及耗时，字段确认预览继续使用 OCR 实际读图路径。

## 验收

1. 灰暗图片生成增强后的 `_ocr_work/*.jpg`，结果元数据标记增强路线。
2. 增强异常或质量退化时仍输出几何校正图，不阻断 OCR。
3. 约 240 万像素测试图片的完整 `prepare_for_ocr` 调用低于 3 秒。
4. 白底图片仍直通；关闭开关时仍直通。
5. OCR 适配器继续读取 `PreprocessResult.ocr_path`。

## 范围外

扫描型 PDF 拆页增强、多候选 OCR 对比和重复 OCR 不属于第一阶段。
